03

Parâmetros do modelo

AJUSTÁVEL

Poisson para golos; binomial negativa para cantos, remates, faltas e cartões com dispersões iniciais próprias. Os indicadores adicionais só são simulados quando existe cobertura nas quatro médias. Modelo exploratório: não incorpora ainda alinhamentos, lesões ou força ajustada dos adversários.
